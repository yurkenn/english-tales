## Üretim istemi

Create a production asset from the LEFTMOST character numbered 01 in the provided concept board. Preserve that exact mascot's identity: closed ocean-blue book with rounded corners, cream page edge along top/right, purple upward bent bookmark like a hair tuft, expressive large white eyes glancing curiously upward to its right, tiny navy eyebrows, gentle smile, tiny blue cheek marks, left hand thoughtfully touching its cheek. Use the lower-left icon crop as the composition reference. Output ONE square image containing ONLY this blue book character on a genuinely transparent background. No rounded-square tile, no background color, no labels, no text, no other characters, no ground shadow. A closeup icon portrait: show complete bookmark above the head, whole face and little thoughtful hand; omit legs, lower book ends in a clean rounded bottom. Center the silhouette comfortably within the square, occupying approximately 80 percent of canvas width and height, with transparent margins on all sides. The face is large and clear. Premium clean vector-like 2D illustration, smooth bold silhouettes, restrained flat shading, exact blue #006CA8, purple #7846BD, cream and navy palette. Do not change to an open book; do not use options 02 or 03. Designed for legibility at 48 pixels and Android adaptive icon clipping.
